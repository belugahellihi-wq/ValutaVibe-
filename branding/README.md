# ValutaVibe — visual identity

Знак состоит из двух V, образующих спокойную восходящую волну. Это отсылка к названию и ритму данных, а не обещание роста курса.

- `logo.svg`: масштабируемый знак на тёмном фоне.
- `logo-1024.png`: готовая квадратная PNG-версия.
- `wordmark.svg`: горизонтальный логотип для страницы проекта.
- `../public/icon.svg`: знак, используемый в интерфейсе и favicon.
- `../android/app/src/main/res/`: Android-иконки и заставка.

Основные цвета: OLED `#050708`, emerald `#5BF0BA`, mint `#D9FFED`. Знак должен сохранять свободное пространство вокруг и оставаться различимым в маленьком размере. Вектор — основной исходник, PNG — экспорт. Проверка товарных знаков не проводилась.
